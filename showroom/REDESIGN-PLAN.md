# Oyeola Online showroom: nine distinct experiences
Updated: 2026-10-12

## Non-negotiable rule
No shared hero composition, global landing-page template or repeated default interaction for different concepts. The layout is chosen for the business problem. All fictional sites are labelled concepts, with illustrative imagery/data; real client links must stay faithful to their actual work.

| Project | Identity | Distinct layout | Core interaction | Primary goal |
|---|---|---|---|---|
| Modu Atelier | Neutral, restrained luxury | Split configurator with near-full-height product image and fixed information rhythm | Fabric selection and room fit | Generate qualified bespoke furniture enquiries |
| Arc & Acre | Cinematic architectural | Full-screen image opening, alternating longform project spreads, project brief | Outdoor-space brief builder | Convert aesthetic interest into meaningful enquiries |
| Stillform | Quiet wellness | Centred typography, arch image, calm sequential flows | Class-mood selector and sample timetable | Reduce new-client uncertainty |
| Kindred Pet | Colourful, welcoming service | Bold illustrated-feeling hero, rounded blocks and practical triage sections | First-visit guidance | Help visitors find appropriate next steps |
| Common Ground | Punchy community poster | Giant wordmark-style headline, full-bleed coffee photo, oversized menu ledger | Illustrated menu filter, event preview | Drive local visits and engagement |
| Fieldnote Books | Avant-garde cultural editorial | Dark typographic posters, overlapping book covers and abstract shelf | Mood-based matching and reading shelf | Create discovery and repeat engagement |
| Arbequina Apartment | Existing real client case study | Warm hospitality-framed original case-study view | Existing case-study presentation | Demonstrate actual client work |
| Objects In Motion | Existing live creative work | Stark gallery-framed live original site | Original site's artwork exploration | Demonstrate a real creative experience |
| Tillman Tough | Existing live industrial work | Compact industrial-framed live original site | Original site's catalogue/quote tools | Demonstrate a real B2B experience |

## Rebuild details
- Original concept HTML pages were replaced rather than applying shared theme changes.
- Three live-client/case-study preview frames were individually styled, but their underlying delivered projects are intentionally not redesigned.
- The showroom project-card treatment reflects individual visual identities.
- Every demo interaction should identify when information is not submitted or booked.
- Subsequent review must test mobile/desktop, keyboard and form interactions on live deployment; a GitHub commit is not a completed deployment smoke test.

## Acceptance criteria for future additions
1. Document a unique visual system before implementation.
2. Sketch a unique page-level information architecture.
3. Demonstrate one domain-specific journey.
4. Audit repeated hero patterns and grid repetition.
5. Clearly label illustrative content and preserve real project provenance.
6. Independently verify the deployment and interactive behavior before claiming live acceptance.
